研究プロジェクト・数論・計算機援用証明

どんな ξ でも、合成数は無限に現れる

と

正の実数 ξ をひとつ選び、7/5 を何度も掛けては、そのたびに整数部分だけを残します。こうしてできる数列には、必ず合成数が無限に現れます。5/2 でも同じです。証明では、ある項から先で、いくつかの小さな素数のどれでも割り切れない項しか現れない数列があったとして、それを有限のグラフに閉じ込め、そのグラフを何も残らなくなるまで刈り込みます。

01結果

累乗の整数部分についての二つの定理

1967 年、Forman と Shapiro は ⌊(3/2)n⌋ と ⌊(4/3)n⌋ に合成数が無限にあることを証明しました。その議論は、どんな ξ > 0 を掛けても成り立ちます。のちに Dubickas と Novikas が 5/4 を加えました。7/5 については最も近い整数、5/2 については 1 だけずらした数列が扱われていました。本研究は、ずらさない整数部分そのものについて証明します。

定理 1 (i)7/5

どんな ξ > 0 に対しても、無限に多くの n で成り立つ

4290 = 2351113

  • 1ステップ法のグラフ証明書、4段階
  • Lean：カーネルで検査

定理 1 (ii)5/2

どんな ξ > 0 に対しても、無限に多くの n で成り立つ

40112098026 = 23711131719232931

  • 語ラベル法の証明書、10段階（素数 5 は不要）
  • Lean：健全性はカーネルで検査、有限の評価は native_decide

系 2どんな ξ > 0 に対しても、⌊ξ(7/5)n⌋ と ⌊ξ(5/2)n⌋ のどちらにも合成数が無限に現れます。法と共通の約数をもつ 31 より大きい項は合成数で、項はいくらでも大きくなるからです。

定理 37/5 では、待ち時間の具体的な上限まで分かります。428 + 12L(P) 歩以内に合成数。

02試してみる

自分で ξ を選ぶ

好きな正の数を入力してください。各項を厳密に計算し、合成数には、それを割り切る最小の証明書の素数を添えます。項をいくら並べても定理の証明にはなりません（それを担うのが有限の証明書です）。それでも、印のついた項が現れ続ける様子は確かめられます。

    03しくみ

    例外を有限のグラフに閉じ込め、何も残らないまで刈り込む

    仮に、⌊ξ(7/5)n⌋ のある項から先に、2, 3, 5, 11, 13 のどれでも割り切れない項しか現れないとしましょう。その先の項の並びを「例外のしっぽ」と呼びます（その項が素数とは限りません。たとえば 323 = 17 × 19 は、5つのどれでも割り切れません）。証明は、例外のしっぽが存在しないことを、次の三段階で示します。

    1

    繰り上がりは小さい

    n 番目の項を Qn と書きます。繰り上がり cn = 5Qn+1 − 7Qn は、いつも −4 から 6 までの 11 個の整数のどれかです。ですから例外のしっぽは、有限個の局所的な規則に従います。4290 を法とする余り、小数部分、繰り上がりの組み合わせ方は、有限通りしかありません。

    2

    有限のグラフが例外のしっぽを閉じ込める

    状態は、項の 4290 を法とする余りと、小数部分が K 等分したどのセルに入るかを記録します。辺は、繰り上がりを添えた、規則にかなう一歩です。例外のしっぽは、どれもこの有限のグラフの中の無限の道になります。7/5 では、状態は最初 960 × 32 = 30,720 個です。

    3

    何も残らないまで刈り込む

    無限に続く道は、やがてひとつの強連結成分の中にとどまります。その中のどの道でも繰り上がりが周期的になってしまうなら、その成分は取り除けます。本物の数列の繰り上がりは周期的にならないことが、初等的な非周期性の補題で分かっているからです。残った部分はセルを四つに分けて細かくし、判定をくり返します。7/5 では第4段階で何も残らず、例外のしっぽは存在しません。

    5/2：辺に語を載せる

    ⌊ξ(5/2)n⌋ で 10 個の素数すべてを一度に入れたグラフを直接作ると、状態は 30,656,102,400 個になります。語ラベル法は代わりに、4 頂点と、−1, 1, 3 の3つだけの繰り上がりから始めます（2 で割り切れない項は奇数で、奇数の項の次の繰り上がりは奇数になるため）。辺に繰り上がりの語をまるごと載せ、枝分かれのない道を正確に縮約し、素数をひとつずつ加えます。そのたびに、語の途中のどの項でも余りを確かめます。作るグラフの最大は 2,856,938 頂点で、最後の出力は空になります。同じ方法で 7/5 の別証明も得られます。

    04待ち時間

    次の合成数まで、どれだけ待つか

    定理 3 P = ⌊ξ⌋ > 13 ならば、0 ≤ n ≤ 428 + 12L(P) のどれかで gcd(⌊ξ(7/5)n⌋, 4290) > 1 となり、その項は合成数です。

    どの項から数え始めても使えるので、13 より大きい項 QN から 428 + 12L(QN) 歩以内に合成数が現れます。合成数どうしの間隔は、項の対数程度より速くは広がりません。証明では、491,520 状態・891,990 本の矢印からなるもう一つのグラフを作ります。そのブロックは 65 段に積み重ねられ、道が各段で過ごせる時間を厳密に足し合わせます。

    05届く範囲と限界

    この方法にできること、できないこと

    論文は、一般の底 a/b について、証明書の方法そのものについての定理も証明しています。

    正規形

    操作を正確に定めると、有限の証明書が存在するのは、あるセル数と、2ab を割らない素数のある有限集合について、ある一つのグラフのすべての巡回成分が位相判定を通るときに限ります。縮約、素数のべき、2ab を割る素数は、証明できる範囲を広げません。

    大きすぎる分子

    a ≥ 2 rad M のとき、この方法は決して終わりません。たとえば 4290 の素数だけでは、7/5 に近づいていく分数 (14k+1)/(10k+1) を、k ≥ 613 ではどれも証明できません。

    素数の予算

    二つの繰り上がりの語を組み合わせると、どのグラフでも排除できない擬軌道ができます。これを防ぐには素数を追加する必要があり、その積 R は次を満たさなければなりません。

    障害であって、反例ではない

    これらの結果が述べているのは、決まった手順が終わらないということです。何かの算術的な主張への反例ではなく、どの底でも合成数が有限個しかない、と言っているわけでもありません。この種の有限の証明書がどこまで届き、どこで届かないかの地図です。

    06追加の結果と未解決問題

    二つの定理の先へ

    再帰的な繰り上がり

    互いに素な a > b ≥ 2 について、軌道の繰り上がりの列が再帰的なしっぽをもつなら、その軌道には合成数が無限にあります（定理46）。

    高さまでの確認

    6 < ⌊ξ⌋ ≤ 540 なら ⌊ξ(6/5)j⌋ の最初の 41 項のどれかが、9 < ⌊ξ⌋ ≤ 718 なら ⌊ξ(9/7)j⌋ の最初の 19 項のどれかが合成数です（定理47）。

    停止問題

    9/7 を含む分数の族 (6t+3)/(6t+1) では、すべての係数についての主張が、ある整数プログラムが必ず止まるかどうかに帰着します（定理58）。

    五つの未解決問題

    1. ほかの底と無限の族。 ほかにどの有理数の底が有限の証明書をもつか。一つの証明書で無限の族を扱えるか。
    2. 有限の高さと、すべての係数。 6/5 と 9/7 の確認を、示した高さの先まで広げられるか。
    3. 再帰性。 素数だけが並ぶしっぽが、再帰的でない繰り上がりをもつことはあるか。
    4. 追加の操作。 もっと鋭い操作で証明できる底は増えるか。停止プログラムは必ず止まるか。
    5. 最小性と部分列。 素数の集合は最小か。番号の等差数列に沿うとどうなるか。素数の項はどれほどまれか。

    07検証

    二重の確認：独立なプログラムと Lean

    二つの実装

    すべての有限の計算は、中心部分を別々に書いた二つの実装で行い、完全な出力を全要素で比較しました。個数やハッシュ値の一致ではありません。

    • 1ステップ法（表1〜3）：コサラジュ法の A とタージャン法の B。B は A を読まずに仕様から書き、比較の前に出力を固定しました。97,772 頂点、168,474 本のラベル付きの辺、94,006 個の成分で一致し、B の検査プログラムはわざと壊した 13 個の証明書をすべて拒否します。
    • 語ラベル法（表4・6・7）：29 組のグラフのファイルすべてが全要素で一致します。

    Lean 4 による形式化

    • 7/5：4段階の証明書を Lean のカーネルの中で検査します。論文の報告によれば、最終的な定理が依存するのは標準の公理 propext、Classical.choice、Quot.sound だけです。
    • 5/2：手順全体を Lean の中で実行し、その健全性の定理はカーネルで検査します。有限の実行には native_decide を使うので、Lean のコンパイラとネイティブな実行も信頼することになります。Python や C++ の成功フラグ、グラフのファイル、ハッシュ値は信頼しません。
    • 形式化の外：定理3、第6〜8節と第10節、付録、表の数値。そこでの根拠は、書かれた証明と A・B の比較です。

    10成り立ち

    この研究の成り立ち

    論文の謝辞には、その成り立ちが詳しく書かれています。出発点は「すべてのミルズ数は無理数ではないか」という著者の問いで、本稿はその問いを解決するものではありません。

    最初の予想のあと、数学的な展開、計算プログラム、文章、そして Lean による形式化は、すべて AI システムが行いました。途中の検討は AI による自動的な批評で、人間の数学者による独立した査読ではありません。著者は証明を自ら検証しておらず、議論、再現可能な計算、形式証明を、読者自身が評価するよう求めています。
