# 有理数底の逆探索：第1回の記録

## 0. 結論と達成範囲

目標は、既知の底を指定して追い込むのでなく、有限証明書とともに新しい既約有理数 a/b を発見することです。算術的な目標は

    すべての ξ > 0 と N に対して、ある n >= max(N,1) があり、
    gcd(floor(ξ(a/b)^n), M) > 1

です。M の素因数より項が大きくなれば合成数なので、これから合成数が無限に出ることが従います。

**今回、新しい底についてこの全係数の結論を確定したわけではありません。**

今回の採用結果は次の3点です。

1. a <= 80、b >= 2、b < a、gcd(a,b)=1 の1,886個を、初期分割 K=4、辺数上限100,000で横断探索。成功は 3/2、4/3、5/4、7/5 の既知4例。残り1,882個は全て辺数上限による打ち切りであり、不可能性の結論ではありません。5/2は別途上限を増やした計算で成功しました。
2. 頂点ごとの小数部分区間を前後から絞り込む操作を追加し、7/5 の同じ素数集合 {2,3,5,11,13} の証明を、初期 K=4、最大60頂点・103辺の段階グラフで実現。異なる計算方式の Python 参照実装で再計算し、8個の入出力グラフの全頂点・全区間端点・全辺・全文字が C++ と一致しました。
3. 5/3 について、23以下の素数だけを使う論文の手続きは、分割数や素数冪指数をいくら増やしても成功しないことを示す、具体的な帰還語証明書を得ました。大きな探索グラフを使わない別の検証器で全条件を確認しました。

第2項は既知の算術的結果の別証明です。第3項は証明手続きの障害であり、5/3 の合成数出現についての反例ではありません。文献全体における優先権・新規性は主張しません。

C++ には安全な整数範囲と入力検査のため、a <= 200、K <= 65536、新素数 <= 997 の制限を付けています。探索の理論的な適用範囲を示す制限ではありません。証明計算は整数演算だけで行い、浮動小数は実行秒数の表示にのみ用います。

## 3. 論文から使う数学

参照元は添付 `paper-en.pdf`, *Finite Graph Certificates for Composite Terms in Rational Floor Sequences* です。

Q_n = floor(ξ(a/b)^n)、θ_n = ξ(a/b)^n - Q_n とし、

    c_n = b Q_(n+1) - a Q_n = a θ_n - b θ_(n+1)

と置きます。論文 Lemma 4 は、a>b>=2、gcd(a,b)=1、ξ>0 のとき c_n は最終的に周期的にならないと証明しています。

論文 Section 4 の語ラベル付きグラフ、全文字位相判定、決定的経路縮約、全途中剰余を検査する素数リフトを使います。Lemma 29 の一般キャリー集合は

    C(a,b) = {c : 1-b <= c <= a-1,
                   c == b-a (mod 2), gcd(c,ab)=1}

です。この一般集合を採用すると、原則として結論の素数集合には 2ab の全素因数が入ります。

7/5 では Lemma 23 により {2,5} の回避だけから

    C = {-4,-2,2,4,6}

が得られます。今回の小さな証明もこの補題を使うので、7を結論の素数集合に追加する必要はありません。

## 4. 今回追加する前後区間伝播

### 4.1 区間付き被覆

各マクロ頂点 u に半開区間 I_u ⊆ [0,1) を付けます。真の軌道を被覆する無限歩道の、頂点 u にいる時刻の小数部分が I_u に入ることを不変条件にします。

語 w=(c_0,...,c_(ell-1)) に対し、その語に沿う小数部分の関係を

    θ_(i+1) = (a θ_i - c_i)/b,
    0 <= θ_i < 1  (0 <= i <= ell)

で定義します。辺 e=(u,w,v) について、I_u から始まり I_v に終わるこの関係の、始点への射影を A_e、終点への射影を B_e とします。これらは空集合または半開区間です。

全語を前進させる操作は `x -> (a x-c)/b`、逆順に後退させる操作は `x -> (b x+c)/a` です。途中の全時刻で [0,1) と交差させます。論文 Proposition 73 の全語区間検査が基礎になります。

### 4.2 伝播補題

A_e, B_e を外側から包含する区間をそれぞれ Atilde_e, Btilde_e とします。どちらかが空の辺を除き、各頂点を

    I'_u = I_u
           ∩ hull( union Atilde_e : e は u から出る辺 )
           ∩ hull( union Btilde_e : e は u に入る辺 )

へ縮めても、真の軌道の十分先の被覆は保存されます。空集合の hull は空集合です。

**証明。** 被覆歩道の最初の頂点を除けば、現在の頂点には実際に使用した入辺と、これから使用する出辺があります。現在の小数部分は前者の B_e と後者の A_e の両方に含まれるため、両 hull の交差にも含まれます。空の外側区間しか持たない辺は使われていません。したがって先頭の有限部分を捨てた歩道が新しいグラフに残ります。操作を有限回繰り返す場合も、始点を有限回先へ移せば同じ結論です。□

この議論は実際の整数 Q_n を使わず、正確な小数部分の関係を満たす擬軌道にも適用できます。左向きの無限尾部では左右を入れ替え、有限個の端の時刻を捨てれば同様です。

### 4.3 整数格子による外側丸め

共通分母 D = K*2^32 を使い、区間を [L/D,U/D) で表します。

前進一文字では

    L' = max(0, floor((aL-cD)/b)),
    U' = min(D, ceil((aU-cD)/b))。

後退一文字では

    L' = max(0, floor((bL+cD)/a)),
    U' = min(D, ceil((bU+cD)/a))。

下端を下へ、上端を上へ丸めるため、真の可能区間を誤って削りません。負数にも数学的 floor を使います。浮動小数の近似判定ではありません。

プログラムは1伝播につき最大300更新、1段階につき最大50回の再分解を行います。固定点に到達しなくても、実行した有限更新は全て健全です。打ち切りを証明成功と読み替えません。

これは論文の基本手続きに区間操作を加えた構成です。「基本手続きの K=4 完全グラフがそのまま成功した」という主張ではありません。また、証明可能な底の集合そのものが広がったとは主張しません。

## 5. 7/5 の小さな再証明

初期 K=4、C={-4,-2,2,4,6}、リフト素数3,11,13です。

| 新素数 | 入力頂点 | 入力辺 | 最終出力頂点 | 最終出力辺 |
|---|---:|---:|---:|---:|
| 初期 | 4 | 14 | 4 | 14 |
| 3 | 8 | 15 | 5 | 12 |
| 11 | 50 | 103 | 5 | 10 |
| 13 | 60 | 96 | 0 | 0 |

11の段階では区間伝播が46辺を排除します。途中で位相判定と縮約を繰り返し、最後に5頂点10辺になります。次の13のリフト後には巡回SCCが2個だけ残り、いずれも位相周期的です。位相周期は8と13です。全キャリーが最終的に周期的になるため、真の無限回避軌道は存在しません。

よって論文と同じ

    ∀ξ>0 ∀N ∃n>=max(N,1): gcd(floor(ξ(7/5)^n),4290)>1

を得ます。合成数の無限出現は項の発散から従います。

論文 Table 4 の語ラベル証明は初期 K=2048、最大5,928頂点・11,276辺でした。今回の対応する段階グラフは最大60頂点・103辺です。ただし区間伝播には繰り返し更新があるため、この比をそのまま実行時間比と解釈してはいけません。初期Kは4でも、途中で各頂点の区間を高精度有理数端点へ縮めています。

追加区間操作を外すと、同じ K=4 と新素数3,11,13では240頂点523辺が残ります。これは `small_75/basic_K4.json` に記録しています。

### 検証の範囲

C++ は初期辺を整数区間公式で列挙し、Kosaraju 法で成分を求め、禁止開始剰余の根集合を使ってリフトします。

Python は全(j,k,c)に直接不等式を当て、Tarjan 法で成分を求め、全非零開始剰余を前進反復してリフトします。区間更新も Fraction による有理数像から外側丸めを計算します。

両者は入出力8グラフについて、延べ136頂点、264辺、449個のキャリー文字と、全区間端点で一致しました。単なる集計値やハッシュの一致ではありません。

ただし同じ数学的仕様に基づく計算です。別の人間研究者による独立監査でも、Leanで形式化した結果でもありません。

## 6. 5/3 の帰還語障害

今回の明示的なデータは

    a=5, b=3,
    m=7*11*13*17*19*23=7,436,429,
    q=3,684,006,
    I=[2/5,1/2],
    |U|=119, |V|=134,
    letters(U), letters(V) ⊆ {-2,2,4}

です。U,V の全253文字は `obstruction_53/return_obstruction.json` に記録しています。

確認した条件は以下です。

- qからU、Vそれぞれに沿って剰余を動かすと、全途中剰余がmと互いに素で、最後はqに戻る。
- 終端小数部分をIのどこに取っても、各語を逆向きにたどる全途中小数部分は(0,1)に入り、最終的な始点はIに戻る。
- UV != VU。
- 全文字が一般キャリー条件を満たす。

これらは論文 Lemma 69 の全仮定です。

**帰結。** 5/3 に対して、使用する素数を

    P23={2,3,5,7,11,13,17,19,23}

に制限した論文の基本手続きは、どの分割数でも、素数冪指数をどれだけ増やしても成功しません。論文で扱う両方向の擬軌道保存的な拡張操作についても同様です。したがって、この種の成功証明書には少なくとも1個、29以上の素数が必要です。

**論理の要約。** UとVは共通の閉区間へ戻す縮小写像を定めます。非周期的な二進列を、等長で異なるブロックUVとVUで符号化すると、非最終周期的なキャリーを持つ無限擬軌道ができます。各ブロックでqへ戻り、途中も単元なので、指定した素数を避けます。これがどの有限分割にも残り、位相周期性による排除を妨げます。素数冪と2abの素因数への持ち上げは Lemma 69 の証明のとおりです。

検証器は探索コードとは異なる計算方式です。剰余を合成数法mにおける閉公式から計算し、全後退接尾語の端点を直接の有限和で評価します。255個の単元剰余と253組の接尾語端点を確認しています。

**重要：** 擬軌道が単一のξによる真の整数部分列であるとは主張していません。合成数の無限出現が偽であることも、5/3ではどんな証明も不可能であることも意味しません。

## 7. 逆探索への反映

今回の横断探索で新しい底は確定していません。探索予算を増やすだけで発見できると示したわけでもありません。

一方、候補の状態を次の3種類に区別できるようになりました。

- **成功証明書あり**：全係数の算術的結論を得る。
- **帰還語の障害証明書あり**：現在の素数集合では、分割だけを増やしても成功しない。
- **資源上限到達**：数学的には未決定。

とくに5/3を再び「23以下の素数を固定してKを増やす」方針で追う必要はありません。新しい素数を入れるか、擬軌道と真の軌道の違いを使う別操作へ進む必要があります。これが、今回の未成功を単なる試行失敗の記録から区別する点です。
